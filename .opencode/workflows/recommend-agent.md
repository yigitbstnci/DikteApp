# Workflow: Recommend Agent

## Purpose

Guide the user when a task appears to need a new specialist.

## Steps

1. Detect capability gap signals.
2. Check whether context or workflow is enough.
3. If agent is justified, name the proposed specialist.
4. Explain why it helps.
5. Ask user how to proceed.

## Options

```text
A) Prepare agent creation plan
B) Continue with current orchestrator
C) Create context only
D) Cancel
```

## Example

```text
Web app detected.
Recommended: Frontend Agent.
Reason: UI architecture, component standards, accessibility checks.
```
