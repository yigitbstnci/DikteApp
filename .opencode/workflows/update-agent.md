# Workflow: Update Agent

## Purpose

Improve existing agents with explicit user requests and structural validation.

## Steps

1. Identify target agent.
2. Capture update request or ask for desired improvement.
3. Analyze current responsibilities and dependencies.
4. Check for conflicts, overlap, or missing context.
5. Preview targeted changes.
6. Ask approval before editing.
7. Validate dependencies after update.

## Output

- Proposed changes
- Risks or conflicts
- Files affected
- Validation recommendation
