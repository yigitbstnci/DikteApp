# Workflow: Manage Context

## Purpose

Create, update, map, or organize reusable system knowledge.

## Operations

- `map`: show context categories and important files.
- `create`: create reusable context for an agent/workflow.
- `update`: revise existing context.
- `organize`: move context into function-based structure.

## Steps

1. Determine whether knowledge is persistent.
2. Choose category and function folder.
3. Draft concise content.
4. Update navigation and registry as needed.
5. Preview before writing.
