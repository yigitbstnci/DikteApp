# Workflow: Manage Context

## Purpose

Create, update, map, or organize reusable system knowledge.

Do not store target-project current state, tasks, decisions, or handoff memory in `.opencode/context` when the project has or should have a project-native context protocol.

## Operations

- `map`: show context categories and important files.
- `create`: create reusable context for an agent/workflow.
- `update`: revise existing context.
- `organize`: move context into function-based structure.

## Steps

1. Determine whether knowledge is persistent.
2. Determine authority: project-native context for project state, `.opencode/context` for reusable MYB knowledge.
3. Choose category and function folder.
4. Draft concise content.
5. Update navigation and registry as needed.
6. Preview before writing.
