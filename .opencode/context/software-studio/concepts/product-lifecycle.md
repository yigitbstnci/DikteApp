# Product Lifecycle

**Core Idea**: Software products move from idea to delivery through clear stages: clarify, scope, design, plan, build, validate, deliver, learn.

## Key Points

- Clarify user, problem, outcome, and constraints before building.
- Scope small enough to ship and learn.
- Design includes UX, data, architecture, and delivery path.
- Validation includes tests, review, acceptance criteria, and handoff.
- Learning feeds future roadmap and context updates.

## Minimal Example

```text
Idea → Clarify → Scope → Design
→ Plan → Build → Validate → Deliver → Learn
```
