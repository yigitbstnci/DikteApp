# Delivery Checklist

**Purpose**: Quick readiness check before handing off software work.

| Area | Check |
|---|---|
| Scope | MVP goals and non-goals are clear |
| UX | Key flows and edge cases are covered |
| Engineering | Implementation plan matches constraints |
| Tests | Relevant tests/checks are run or documented |
| Security | Secrets, auth, and data risks are reviewed |
| Docs | Usage/setup notes are available |
| Handoff | Known limitations and next steps are listed |
