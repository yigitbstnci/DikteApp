# Idea to Delivery

**Core Idea**: Use one compact workflow to move a product request from vague idea to validated delivery.

## Steps

1. Capture goal, users, constraints, and success metric.
2. Define MVP scope and non-goals.
3. Identify required specialists or missing context.
4. Draft UX/product behavior and technical plan.
5. Break into implementation tasks.
6. Validate with tests, review, and acceptance checklist.
7. Deliver summary, usage notes, and next actions.

## Minimal Example

```text
"Build CRM dashboard"
→ Ask target users + KPIs
→ Recommend Frontend Agent if recurring UI work
→ Plan MVP widgets
→ Validate before delivery
```
