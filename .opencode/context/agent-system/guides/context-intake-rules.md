# Context Intake Rules

**Core Idea**: Before creating a specialist agent, ask what persistent knowledge it needs and whether the user must provide it.

## Ask When Missing

- Domain standards: frameworks, tools, terminology, constraints.
- Quality rules: acceptance criteria, security, performance, accessibility.
- Patterns: naming, file structure, component/API style.
- Boundaries: what the agent should not do.
- Examples: preferred outputs or previous good work.

## Options to Offer

```text
A) Answer intake questions now
B) Extract context from existing files
C) Create minimum draft and refine later
D) Cancel agent creation
```
