# Create Agent Workflow

**Core Idea**: New agents are created through interview, capability-gap check, context intake, preview, and approval.

## Steps

1. Capture requested capability and use cases.
2. Check if existing orchestrator/context/workflow is enough.
3. If agent is justified, define role, boundaries, inputs, outputs.
4. Identify required context and missing user knowledge.
5. Ask intake questions or offer minimum draft mode.
6. Preview agent, context, command, workflow, and registry changes.
7. Create only after approval.
8. Recommend `/check-context-deps`.
